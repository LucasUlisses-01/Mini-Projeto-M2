# Mini-Projeto M2

API REST de gerenciamento de tarefas feita em Node.js com Express, Sequelize e SQLite, seguindo o padrão MVC.

## Funcionalidades
- Listar tarefas
- Criar tarefa
- Atualizar tarefa
- Deletar tarefa

## Tecnologias
- Node.js
- Express
- Sequelize
- SQLite
- ES Modules

## Como rodar

1. Clone o repositório:

git clone https://github.com/LucasUlisses-01/Mini-Projeto-M2.git

2. Instale as dependências:

npm install

3. Rode o servidor:

npm run dev

4. Teste as rotas no Postman:

GET /tarefas  
POST /tarefas  
PUT /tarefas/:id  
DELETE /tarefas/:id

A API estará disponível em:
http://localhost:3000/tarefas
